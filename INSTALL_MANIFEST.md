## Install order and parenting

Modules are required by name through `script.Parent`, so names and parenting must
match exactly. There is no load-order requirement among the shared modules — the
require graph is acyclic — but the containers must exist first.

1. `ReplicatedStorage` → create Folder **`MinecraftShared`**, then place all 13
   ModuleScripts inside it with the exact names listed above.
2. `StarterPlayer.StarterPlayerScripts` → create **`MinecraftClient`** (LocalScript),
   **`InputController`** (ModuleScript), **`InputDebugOverlay`** (ModuleScript).
   The two ModuleScripts must be siblings of the client script.
3. `ServerScriptService` → create **`MinecraftServer`** (Script).
4. `workspace.World` may be created before or after the scripts start. The adapter
   looks for it at load and rescans whenever the folder appears, disappears, is
   renamed or reparented, or when registered part geometry changes (debounced by
   `MovementConfig.Collision.RebuildDebounceSeconds`). Each rebuild swaps in a new
   world; nothing is ever registered twice. Parts over the per-box cell cap are
   rejected and reported, never clipped.

## Interface changes in this revision

The movement `State` shape and the four RemoteEvent names are unchanged. The snapshot
envelope gains `RootToFeetOffsetStuds` and `SchemaVersion` becomes 3; generation/reset
handling is unchanged. These are the changed interfaces:

- `MovementMath.feetBlocksToRootStuds(feet, rootToFeetOffsetStuds)` — offset is now
  a required second argument.
- `MovementMath.rootStudsToFeetBlocks(root, rootToFeetOffsetStuds)` — same.
- `MovementMath.toRootCFrame(state, rootToFeetOffsetStuds, presentationOffsetBlocks?)`
  — offset inserted before the optional presentation correction; raises on a
  non-finite or non-positive offset.
- `RigOffset` (new ModuleScript): `fromGeometry`, `fromRig`, `measure`, `describe`;
  returns `{ Studs, Source, HipHeight?, RootHeightStuds?, Detail? }`.
- `Collision.cellCount(box)` (new) — broad-phase cell count before registration.
- `Reconcile.Snapshot` gains `RootToFeetOffsetStuds` (studs, finite, > 0 and within
  `Units.MaxRootToFeetOffsetStuds`); `MovementConfig.SchemaVersion` is 3.
- `CollisionAdapter.Report.Oversized` (new count) and `Rejection.Category` (new);
  `registerPrimitive` can now return `Category = "Oversized"`.
- `CollisionAdapter.watch`, `.rebuild`, `.scheduleRebuild`, `.stopWatching` (new);
  `watch` returns a live handle whose `.World` must be read at use time.
- `MovementConfig.Units.RootToFeetOffsetStuds` removed; replaced by
  `RootToFeetOffsetStudsFallback` and `MaxRootToFeetOffsetStuds`.
- `MovementConfig.Collision.RebuildDebounceSeconds` (new).
- `MovementState.fromSnapshot` / `isPlausible` and `Reconcile.parseSnapshot` no
  longer compare `LastAppliedInputSeq` with `ServerTick` (F1).

## ClassName notes

The `.client` and `.server` filename suffixes are repository conventions only. They
do not determine ClassName: `MinecraftClient.client.lua` must be a **LocalScript**
under `StarterPlayerScripts`, and `MinecraftServer.server.lua` must be a **Script**
under `ServerScriptService`. All other `.lua` files are **ModuleScripts**.

## Expected top-level return

nothing and have no top-level `return`; they are self-contained entry points that
run to completion and leave their loops and connections active.
